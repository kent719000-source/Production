6. つまずいたこと（チームの参考に）
Spring Boot のエラーは、Eclipse のコンソールでは赤ではなく黒い文字で出る。 Ctrl + F で Exception を検索すると見つかる
ClassNotFoundException: org.apache.jsp... は2回目以降のエラー。 本当の原因は、1回目に開いたときの JasperException に行番号つきで出ている。再起動してから1回だけ開くと見つけやすい
JSP のエラーは、エラーの行より前に原因があることが多い。 > の閉じ忘れや、<c:forEach .../> の / の付けすぎなど
JSP の include は /WEB-INF/jsp/common/header.jspf のように / から書く。 common/header.jspf だと、フォルダの中の JSP から読めない
日付の入力欄を Form で受けるときは @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) を付ける。 無いと正しい日付でも入力形式エラーになる
