## ✅ 2. 決まったこと

「1. これから直すところ」の理由はここ。2-1〜2-14 と 1-1〜1-12 は詳細設計書に反映済み（1-7 は 2-18 で取りやめ）。2-18 はこれから詳細設計書も直す（📙）。2-15〜2-17 は DB を正として Excel を直す（D-14〜D-16）。

### イベント章の方針

| No | 項目 | 決定 |
|:---:|---|---|
| 1-1 | 一覧のJSP | `event/calendar.jsp` |
| 1-2 | カレンダー | Service で「週→日」に組み立て、Model には `calendar` 1つだけ。トップのミニカレンダーも同じもの |
| 1-3 | ループ変数 | 週は `w`、日は `d` |
| 1-4 | 概要ペイン | バーの data 属性から JS（`static/js/calendar.js`）で表示。通信なし。`fn:escapeXml` でエスケープ |
| 1-5 | ペインの里親 | 紐づいているときだけ表示 |
| 1-6 | 完了の操作 | スタンプ欄のボタンで `POST /event/{id}/complete`。ボランティアは押せない |
| 1-7 | ~~完了時の個体更新~~ | **2-18 で取りやめ**（完了しても個体は自動で更新しない） |
| 1-8 | 登録フォームの対応スタッフ | 入れない（完了にした人が自動で入る） |
| 1-9 | 里親の必須 | 種別がトライアル開始・譲渡のとき必須 |
